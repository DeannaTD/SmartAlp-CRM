User interface overview

When you first log in to the app, you will see the following screen:

The app consists of the following elements:

  1. Navigation bar
  2. Main content area
  3. Quick actions bar

Navigation bar

The navigation bar allows you to navigate through the app. It contains the following links:

  • Structure
  • Branch menu
  • Access
  • Add user
  • Settings
  • Logout

Navigation bar is opened by default, but if you want to toggle it, press the arrow icon.

Content area

The content area displays the main content of the app. It will change depending on which link you click in the navigation bar.

Quick actions bar

The quick actions bar contains two icons for "Log out" and "Home" links.

Structure of the system

The system is divided into the following sections:

  • Division
  • Branch
  • Group

Account status

Each user in the system has one of the following statuses:

  • Active
  • Blocked
  • Archived

Active users can log in to the system and perform actions. Blocked users cannot log in, but their data is still stored in the system. Archived users are hidden from the system and cannot log in.

Creating users

To create a new user, click on the "Add user" link in the navigation bar. You will see the following screen:

Fill in the form with the user's information and press "Create".

User login information is generated automatically and will be shown in the confirmation window. By default password is equal to username (must be changed by user after login). If username happens to be too short to be set as a password, "1234" is added to the end of it. For example:

User named "James Potter" will have following credetials: "jpotter" as username, "jpotter" as password

User named "James Lee" will have following credentials: "jlee" as username, "jlee1234" as password

To create a user under the role "Mentor", you need to assign them a division from a drop-down list. This action is not needed to add Managers and Supervisors.

Managing the structure

To manage the structure of the system, click on the "Structure" link in the navigation bar. You will see the following screen:

Division management

  • To create a new division:
    1. Press on "Add new division"
    2. Enter the name of the division
    3. Press "Create"
    4. Wait for the confirmation and page reload
  • To edit an existing division:
    1. Press on the name of the division you want to edit
    2. Change the name of the division (name must not be empty)
    3. Press "Save"
    4. Wait for the confirmation and page reload
  • To delete an existing division:
    1. Press on the name of the division you want to delete
    2. Press "Delete"
    3. Wait for the confirmation and page reload
    4. Deleting a division will erase all the data of it's branches, groups and students. This data cannot be restored

Branch management

  • To create a new branch:
    1. Press on a plus sign next to division name
    2. Enter the name of the branch
    3. Enter the address - it can be a locaiton or a description of the branch
    4. Press "Create"
    5. Wait for the confirmation and page reload
  • To edit an existing branch:
    1. Press on the "Edit" icon next to the branch you want to edit
    2. Change the name or address of the branch (name must not be empty)
    3. Press "Save"
    4. Wait for the confirmation and page reload
  • To delete an existing branch:
    1. Press on the name of the branch you want to delete
    2. Press "Delete"
    3. Wait for the confirmation and page reload
    4. Deleting a branch will erase all the data of it's groups and students. This data cannot be restored

Groups

Branches contain groups and students. Group is the lowest level of the system. To manage them, click on the "Branch menu" link in the navigation bar. You will see the following screen:

In this section you can create and edit groups, add new students and look over the attendance of each of them.

Group management

  • To create a new group:
    1. Press on a plus sign next to branch name
    2. Choose group's timetable and assign a mentor
    3. Press "Create"
    4. Wait for the confirmation and page reload
  • To edit an existing group:
    1. Press on the group you want to edit
    2. Change group's timetable or assigned mentor
    3. Changes to group's settings are saved automatically (without pressing confirmation buttons) and cannot be restored to original values

Student management

  • To add a new student:
    1. Press on a "Add new student" link in group view
    2. Enter student's information
    3. Press "Create"
    4. Wait for the confirmation and page reload
  • To edit an existing student:
    1. Press on a card icon next to the student you want to edit
    2. You can change student's information
    3. Press "Save"
    4. Wait for the confirmation and page reload
  • To transfer student to another group:
    1. Press on a card icon next to the student you want to edit
    2. Choose a new group in "Group" drop-down menu
    3. Press "Save"
    4. Wait for the confirmation and page reload
  • To deactivate student's account:
    1. Press on a card icon next to the student you want to block/archive
    2. Press on "Block student" or "Archive student" to change account status
    3. Wait for the confirmation
    4. If you blocked a student, press "Save"
    5. Blocked student will be shown with a lock icon next to the name
    6. Archived student will no longer be visible in group view
    7. Deactivating of an account does not lead to information loss, but removes an ability to log in

Access management

Access management allows you to control users and their access to the system. To manage access, click on the "Access" link in the navigation bar. You will see the following screen:

Access management

  • To add an access to a supervisor:
    1. Press on a plus sign next to the "Supervisors" cell
    2. Choose a supervisor in the drop-down menu
    3. Press "Create"
    4. Wait for the confirmation and page reload
  • To add an access to a manager:
    1. Press on a plus sign next to a needed branch
    2. Choose a manager in the drop-down menu
    3. Press "Create"
    4. Wait for the confirmation and page reload
  • To remove an access:
    1. Press on a minus sign next to the name of a user
    2. Wait for the confirmation and page reload

Users listings

Above the access management table you can see links to see users in the system in roles "Manager" and "Supervisor". Press on the link to see the listing of users.

On this page you can block/unblock and archive/restore user accounts by pressing the corresponding action cell

Profile settings

To change your profile settings, click on the "Settings" link in the navigation bar. You will see the following screen:

Here you can change your password and profile picture. It is not possible to change any other personal information
